---
name: House-style rules need format scoping
description: SCREENPLAY_STYLE is injected into every prose pass across ALL formats — categorical new rules must carry format exemptions.
---

The shared house-style block binds every prose pass for every project format (drama, documentary, commercial, etc.), and it is appended AFTER the format brief, so a categorical rule overrides format grammar.

**Why:** A dialogue-conflict layer ("every line carries subtext", "facts only as weapons") written as absolutes would have pulled documentary testimony/narration and required commercial copy (product promises, supers, end cards) away from their intended informational register — caught in review.

**How to apply:** Any new absolute house-style rule must either state its scope inline (e.g. "binds DRAMATIC dialogue; documentary testimony, VO beds, archive and commercial copy are exempt") or be injected conditionally per format. Same trap exists in BUILD prompts, not just prose style: the story-world builder is shared by all formats, and a categorical premise rule ("question, never message") broke commercial's promise-led grammar — plumb the format id into shared build prompts and branch (commercial = promise-led; the open question lives only in the dramatic wrapper). Related: deterministic audit findings (facts, e.g. an unbroken word-count run) must never be suppressed by fuzzy-matching a model's free-text notes — keep both and tag the deterministic note with a structured field instead.
