---
name: Screenplay audit boundaries
description: Durable rules for production-unit modeling and truthful whole-film screenplay critiques
---
Production slugline units must remain derived from screenplay heading blocks; do not persist a second scene model beside dramatic story scenes.

**Why:** A dramatic scene and a production unit are different views of the same screenplay. Persisting both as independent structures invites drift, while derived units already support multiple locations, intercuts, scheduling, and coverage without migrating existing films.

**How to apply:** New formatting, breakdown, and production features should consume the live slugline derivation and keep only user-authored overlays persistent.

A whole-film critique must represent every drafted scene, preserve the ending/climax, disclose any context shortening, and exclude value-charge or beat-intent metadata when claiming to judge the finished page.

**Why:** Head-only truncation can omit the climax while still producing a confident thematic-payoff verdict; development metadata can bias the reviewer to reward an intended turn that the prose never dramatizes.

**How to apply:** Use bounded per-scene head-and-tail packing with a strict aggregate cap (including separators), and refuse explicitly rather than making complete-film claims when minimum coverage cannot fit.
